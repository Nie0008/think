# 通用场景与补充方法

<!-- Modified 2026-10-18: replaced personal scenarios and machine paths with generic examples. -->

以下是帮助选方法的通用情境，不代表任何组织、个人或产品的真实状态。实际目标、偏好、约束和效果以当前任务的原始材料为准。

## 场景适配

| 当前问题 | 可采用的切入 | 有用的产物 |
| --- | --- | --- |
| 多个部门对流程改进的理解不同 | 软系统梳理问题理解，价值聚焦分开目标与做法；行动冲突时检查冲突消解图 | 角色需求、现行规则、候选改变及待确认项；缺席参与者的意见保留为假设 |
| 产品方案总在几个熟悉选项里打转 | 目标不清时用价值聚焦，组合不足时用形态分析，对象尚不可判定时用 C–K | 目标、方案维度、完整候选及对应的知识任务 |
| 设计一门课程或一份操作指南 | 目标已清楚时直接设计；方案同质时考虑形态分析 | 读者任务、准备材料、操作与可检查作品；设计完成不代表已有人试用 |
| 多个项目争用同一时间与预算 | 组合决策检查约束、依赖与复用；关键收益未知时用信息价值确定下一项检查 | 可行组合、总资源、取舍依据与翻转条件；单项排名不能替代组合检查 |
| 成熟活动占满资源，新方向难以启动 | 生态循环识别资源陷阱；探索与交付确需长期共存时考虑两极管理 | 保留、重构、投入或退出的候选动作及依据；阶段标签不能代替义务检查 |
| 计划从人工流程逐步迁移到自动化 | 动态适应路径 | 当前容量、提前触发信号、迁移准备期与备选路径；缺数据时先测量 |

方法之间的先后取决于实际输入。目标、材料已清楚时可以直接执行，不因场景名称固定套用一整套方法。

## 软系统方法 SSM

适用：参与方对“问题是什么”理解不同，直接汇总功能清单难以协商。

从已有访谈、规则及流程材料画角色、关系、冲突与约束；分别记录各方有依据的世界观，写出有目的活动的根定义。必要时用 CATWOE 检查受影响者、行动者、转换、世界观、可决定系统存续者与环境约束。构造活动模型，与实际做法比较，形成既有系统价值又可被当前情境接受的改变候选。

产物：不同问题理解、活动模型差异、协商与待确认项。缺席参与者的意见只能标假设；AI 不能宣布各方已认可。来源：[Checkland 原始回顾](https://proceedings.systemdynamics.org/1999/PAPERS/KEYNOTE3.PDF)、[Cambridge IfM 的 SSM 与 CATWOE 说明](https://www.ifm.eng.cam.ac.uk/research/dstools/soft-systems-methodology/)。

## 组合决策 PDA

适用：需要选一组项目，存在共享预算、时间、前置依赖、互斥或复用收益。

列候选活动、资源占用与目标贡献，明确必须完成项、依赖和可复用准备成本；小组合用实际计算枚举可行集，比较整体结果并保留合理取舍。收益不确定时保留范围或条件，不编造收入、转化率或效用权重。

产物：约束与依赖、可行组合、总资源及取舍。单项得分排序或收益／成本排序不能代替组合检查，复用成本只计一次。调整已开始的计划时计入已花资源与剩余成本，不把已投入时间重新当作可用预算。来源：[Salo、Keisler 与 Morton 的方法文](https://pubsonline.informs.org/do/10.1287/LYTX.2011.06.03/full/)。

## 生态循环 Ecocycle

适用：活动不断累积，成熟活动占满资源，新方向得不到投入。

列真实占用资源的活动，尝试映射到诞生、成熟、创造性破坏与更新；核对僵化及稀缺陷阱，对分歧保留依据，提出具体移动、重构或退出动作。

产物：组合图、资源陷阱与动作候选。阶段是讨论工具，不能仅因不新鲜就停止关键基础工作；退出仍须核查义务、依赖与授权。来源：[Liberating Structures 原始方法页](https://www.liberatingstructures.com/ecocycle-planning)。
