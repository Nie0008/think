# 目标与方案

<!-- Modified 2026-10-18: generalized evidence wording for public use. -->

按当前缺口读取相应章节。下面是面向 Agent 的简化用法，方法来源不等于当前任务效果已验证。

## 价值聚焦思考 VFT

适用：问题停留在“买哪个工具、做哪个功能”，尚未说清真正追求的结果。

输入是当前选择、用户目标与硬约束。用“改善／减少＋对象”写结果，逐项追问为什么重要，区分根本目标与实现手段；结合时间、质量、成本及相关人的需要补遗漏。围绕每个根本目标产生路径，再组合成候选，回到同一目标表比较。

产物：目标—手段关系、新增候选、仍缺的依据。目标是待用户确认的偏好，不能由 AI 擅自定权重；已有明确目标时不必重做。

来源：[Keeney 本人说明](https://ralphkeeney.com/)、[Bond、Carlson 与 Keeney 的目标生成研究](https://www.scheller.gatech.edu/directory/research/marketing/bond/pdf/bond-carlson-keeney-da-2010.pdf)。研究支持特定条件下补全目标，不证明通用业务收益。

## 广义形态分析 GMA

适用：目标基本清楚，候选方案总是重复旧组合。

将设计对象分成少数关键维度，每维列出可区分的状态；从每维取一个状态生成配置。先检查状态间的逻辑矛盾与有依据的经验不相容，记录排除理由及不确定性；价值取舍单列，在一致性检查后筛选，避免把“不喜欢”写成“不可能”。对保留的完整配置再检查整体可行性和成本。

产物：维度—状态表、不相容关系及值得细化的完整候选。形式组合数不是可行方案数，两两相容也不保证整体可实施。维度仍不稳定、对象定义需要改变时，可考虑 C–K。

来源：[Tom Ritchey 的原始方法说明](https://www.swemorph.com/ma.html)。

## 杠杆思考

适用：投入不断增加，结果却主要依赖反复亲自做；或流程反复卡住，需要寻找能带动整体结果的着力点。

输入是当前目标、实际流程、投入与结果记录、可用资源和硬约束。先明确希望改善的是完成量、质量、耗时还是触达，沿“投入—活动—结果”找限制整体结果的环节。材料不足时把瓶颈保留为假设，列出需要测什么，不凭最忙或最显眼的环节下结论。

围绕限制环节生成杠杆候选：改变信息流、反馈或规则，让系统更容易产生目标结果；把已有能力做成可复用的模板、工具、自动化或内容，让后续使用不必重复全部劳动。协作和传播也可成为候选，但要说明谁会使用、如何触达、各方需要投入什么；不必把每类都列一遍。

对候选写清“改哪里—通过什么机制起作用—受什么条件限制”，检查局部提速是否只是把排队或返工转移到下一环节。保留直接处理的方案，按同一时间范围比较结果与总成本，计入制作、适配、维护、审核、获客和故障处理。可量化时，用有依据的使用次数与单次净节省估算能否覆盖前期投入；目标是质量或触达时检查对应结果，不强行折算成收入。缺数据就给条件或小范围验证，不编收益倍数。多个候选争用资源时接组合决策，关键未知未明时接信息价值分析。

例如，重复答疑可比较继续逐次回答，与制作可搜索示例、模板或自助工具；先检查问题是否足够重复、使用者能否找到并用对，以及维护是否划算。只有少量使用时，直接回答可能更合适；用户积累与收入按各自目标评价，不能把关注、咨询写成付费或利润。

产物：值得优先尝试的着力点、作用机制、总成本、成立条件及下一项验证。工具数量、自动化比例和传播量不能替代目标结果；错误和损失也可能被放大，扩展前保留必要审核与恢复办法。选择了杠杆不代表已获授权去发布、付费或改变规则。

来源：[Donella Meadows《Leverage Points》](https://donellameadows.org/archives/leverage-points-places-to-intervene-in-a-system/)讨论系统干预点；[Naval 本人访谈中的产品与媒体杠杆](https://nav.al/rich)讨论成果复制与规模。这两种视角不同，本节将其转为候选生成与检查提示，不保证小投入必有大回报，也未验证当前模型或业务中的效果。

## 概念—知识双空间扩展 C–K

适用：要创造的对象或服务，在当前知识下尚不能判断是否成立，既有类别限制了探索。

把有依据、可判断的知识放入 K，把尚不可判定的目标概念放入 C。为 C 添加属性形成分支，也允许改变对象定义；每个分支列出必须获得的知识，再通过调查、学习或试验补充 K，回到 C 修订、扩展或关闭分支。

产物：概念树、知识与来源、分支对应的知识任务。AI 提出的解释保留为假设，不自动进入 K；普通已知选项比较无需套用此法。

来源：[Le Masson、Hatchuel 与 Weil 的理论章节](https://www.tmci.minesparis.psl.eu/wp-content/uploads/2021/01/1.2.pdf)。理论与教学示例不能代替具体应用的效果验证。
